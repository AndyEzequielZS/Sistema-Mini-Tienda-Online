# Sistema Mini Tienda Online

Sistema de gestión comercial desarrollado en **Visual Basic** con **Windows Forms** y **SQL Server**.

## Funcionalidades
- Inicio de sesión
- Gestión de clientes
- Gestión de productos e inventario
- Registro de ventas con carrito de compras
- Cálculo automático de totales

## Tecnologías
- Visual Basic
- Windows Forms
- .NET Framework
- SQL Server
- Visual Studio
